## Exobiology color variants (GPL-3.0)

`plugin/organic_variant_data.py` says which color variant a species takes, from the class of the star its body orbits or a surface material (a few species have one fixed color). It is generated by
`scripts/gen_organic_variants.py` from the `bio-criteria` files of [njthomson/SrvSurvey](https://github.com/njthomson/SrvSurvey), licensed GPL-3.0, the same license as WNTB; only the color
rules are taken, and the code that uses them is WNTB's own. The predictions were checked against the commander's own journals with `scripts/verify_organic_variants.py` (2026-10-16: 397 samples
whose star and materials the journal gave, every one matched).

## Exploration Value: scan-value constants (GPL-3.0)

The per-planet-class base values and the mass exponent in `plugin/scan_value.py` (used by `plugin/exploration_value.py`) are the
community's figures for Frontier's exploration payout, as published in
[Faber38/CMDRHelper](https://github.com/Faber38/CMDRHelper), licensed GPL-3.0, the same license as WNTB.

## Landing Assist: pad layouts (GPL-2.0 or later)

The pad layouts drawn by `plugin/landing.py` follow
[bgol/LandingPad](https://github.com/bgol/LandingPad), licensed GPL version 2 or later, which allows
use under the GPL-3.0 that WNTB carries: the starport pad table, shell sizes and pad sectors (which the
game's station design dictates), the fleet carrier and squadron carrier pad rectangles, and the list of
colonisation ship market ids. The code that draws them is WNTB's own.

## Colonization: what each building costs (GPL-3.0)

`plugin/colonisation_costs.json` is a copy, unchanged, of `SrvSurvey/colonization-costs2.json` from
[njthomson/SrvSurvey](https://github.com/njthomson/SrvSurvey) (last changed there 2026-03-20, commit c5cb2db), licensed GPL-3.0,
the same license as WNTB. It lists the tons of each commodity every kind of building needs, which the Planned Builds window uses
to size a plan before any depot has been visited (`plugin/build_costs.py` reads it; that code is WNTB's own). The costs are the
game's, as that project's author compiled them, and can go out of date when the game changes them.

## Colonization: market categories (GPL-3.0)

`plugin/commodity_categories.py` lists the market category of each colonization commodity, which the overlay shopping list uses to group
its rows as the in-game market does. The grouping is taken from `ColonyData.mapCargoType` in
[njthomson/SrvSurvey](https://github.com/njthomson/SrvSurvey), licensed GPL-3.0, the same license as WNTB; the code that uses it is
WNTB's own. The order of the list (alphabetical at a construction site, grouped elsewhere, dimmed when the market does not sell a
commodity) follows that project's shopping overlay.

## Engineering material names, types and grades

`plugin/materials_data.py` is generated from the `material.csv` published by [EDCD/FDevIDs](https://github.com/EDCD/FDevIDs), which declares no
license. The names are Frontier's own; the type (Raw, Manufactured, Encoded) and the grade (its `rarity` column, 1 to 5) are game facts. Nine Thargoid-war
and chip materials were added from EDDiscovery's item list (see the section above).

## Ship engineering planner: journal blueprint names

`plugin/journal_blueprints.py` links the names the journal uses for engineering blueprints and experimental effects (`FSD_LongRange`,
`special_fsd_heavy`) to the names in WNTB's blueprint table. The journal names come from [EDCD/coriolis-data](https://github.com/EDCD/coriolis-data)
(`modifications/blueprints.json` and `specials.json`; the repository declares no license, so only the names are used, as game facts, with credit) and
the join uses the Coriolis UUID that each row of [msarilar/EDEngineer](https://github.com/msarilar/EDEngineer)'s `blueprints.json` records (MIT; see the
engineering blueprints section above). The mapping from ship items to module types is WNTB's own, written from the names in
[EDCD/FDevIDs](https://github.com/EDCD/FDevIDs) `outfitting.csv` (no license declared; Frontier's own names). The format a pasted ship loadout is read
in is the journal's `Loadout` event, which EDSY and Coriolis export as SLEF ([EDCD/slef-specification](https://github.com/jixxed/slef-specification)).
No code was taken.

## Rare goods table

`plugin/rare_goods.json` (behind the Rare Goods Finder) lists each rare commodity with the system and station that sells it, its pad size, what is illegal
where, its cost and its Powerplay eligibility. It was compiled from public game data and community lists of the rare goods, which are game facts, with three
ids looked up once: each system's coordinates from [EDSM](https://www.edsm.net/), each commodity's id on [Inara](https://inara.cz/) (used only to open its page)
and each system's id from [Spansh](https://spansh.co.uk/). None of those services' code or pages are bundled, and the file is not a copy of any one list.

## Commodity names (Trade)

`plugin/trade_commodities_data.py` is generated from the `commodity.csv` published by
[EDCD/FDevIDs](https://github.com/EDCD/FDevIDs), which declares no license. The names are Frontier's own, and
Spansh's market search needs them exactly.

## Ship landing-pad sizes (Trade)

The pad class of each ship in `plugin/trade_ship.py` (small, medium or large) was read from the ship data in
[EDCD/coriolis-data](https://github.com/EDCD/coriolis-data) (`properties.class`). These are game facts; no code
or data file from that project is bundled.

## Notable Bodies: rules, thresholds and green gas giant temperatures (MIT)

The rules and numeric limits in `plugin/notable_rules.py` (landable above 29.4 m/s^2, landable radius above
18,000 km, rotation or orbit under 8 hours, eccentricity above 0.9, 5 of the 6 premium FSD materials, wide
ring, close orbit, shepherd moon, close and colliding binary) follow the default criteria in
`ObservatoryExplorer/DefaultCriteria.cs` of [Elite Observatory](https://github.com/Xjph/ObservatoryCore),
Copyright (c) 2021 Jonathan Miller, MIT license. The implementation is WNTB's own.

The list of confirmed green gas giant surface temperatures comes from CMDR Arcanic's research
([ed-ggg.github.io/edggg](https://ed-ggg.github.io/edggg/)), as compiled by DaftMav into the community
"Custom Criteria for Everyone" file maintained by CMDR Julian Ford. They are measured values from the game;
that file states no license, so only the numbers are used, with credit.
